Estadística Descriptiva · Tema 1
Medidas de Locación
Media, mediana, moda y cuándo usar cada una

Medidas centrales

  • Media: suma de valores ÷ n. Sensible a extremos.
  • Mediana: valor central al ordenar. Robusta ante outliers.
  • Moda: valor más frecuente. Útil para categóricas.
  • Media truncada: elimina el x% de extremos antes de promediar.
  • Media ponderada: cada valor tiene un peso diferente.
🏦
Metáfora
"La mediana es más honesta que la media cuando hay ricos en la sala. Si Carlos Slim entra a una habitación de 100 personas, el salario promedio se dispara — el salario mediano no se mueve."
Caso Real
El INEGI reporta salario mediano (no medio) porque en 2023 el mediano fue $7,310/mes versus un promedio $12,000+ distorsionado por extremos.
Python
import numpy as np
from scipy import stats

salarios = [12000, 14000, 15000,
            16000, 18000, 850000]

print(f"Media:          ${np.mean(salarios):>10,.0f}")
print(f"Mediana:        ${np.median(salarios):>10,.0f}")
print(f"Media truncada: ${stats.trim_mean(salarios, 0.1):>10,.0f}")

# Salida esperada:
# Media:          $  157,500
# Mediana:        $   15,500
# Media truncada: $   15,000

¿Cuándo usar cuál?

  • Media: distribuciones simétricas sin outliers
  • Mediana: datos con sesgo o valores extremos (ingresos, precios)
  • Moda: variables categóricas (color favorito, partido político)
  • Media truncada: calificaciones deportivas (saltos, patinaje)
Estadística Descriptiva · Tema 2
Medidas de Variabilidad
Rango, varianza, desviación estándar, IQR y percentiles

Medidas de dispersión

  • Rango: max − min. Simple pero sensible a outliers.
  • Varianza (σ²): promedio de desviaciones al cuadrado.
  • Desviación estándar (σ): raíz cuadrada de la varianza. Mismas unidades que los datos.
  • Coef. de variación: (σ / μ) × 100. Compara dispersión entre escalas distintas.
  • IQR: Q3 − Q1. Rango del 50% central. Robusto ante outliers.
  • Percentiles: valor por debajo del cual cae el x% de los datos.
🌡️
Metáfora
"Dos ciudades con temperatura promedio 25°C: una siempre a 25°, la otra va de 5° a 45°. La desviación estándar te dice cuál es cuál — misma media, mundos distintos."
Caso Real
Las aseguradoras calculan primas con desviación estándar de comportamiento. Un conductor variable (20–180 km/h) paga más que uno estable aunque su velocidad promedio sea igual.
Python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np

df = pd.DataFrame({
  'Ciudad_A': np.random.normal(25, 2, 365),
  'Ciudad_B': np.random.normal(25, 12, 365)
})

print(df.describe().round(2))

# Boxplot comparativo
df.boxplot(figsize=(8, 5))
plt.title('Variabilidad de temperatura')
plt.ylabel('Temperatura (°C)')
plt.show()

Interpretación rápida

  • σ pequeña → datos concentrados cerca de la media
  • σ grande → datos muy dispersos, alta variabilidad
  • IQR estrecho → 50% central homogéneo
  • Boxplot con bigotes largos → presencia de outliers
Estadística Descriptiva · Tema 3
Distribuciones y Visualización
Normal, sesgada, bimodal · Histograma vs KDE

Tipos de distribuciones

  • Normal (campana de Gauss): regla 68-95-99.7. Simétrica alrededor de la media.
  • Sesgada positiva (derecha): cola larga a la derecha. Ingresos, precios.
  • Sesgada negativa (izquierda): cola larga a la izquierda. Edad de jubilación.
  • Bimodal: dos picos. Señal de dos subpoblaciones mezcladas.
  • Histograma: frecuencia por intervalos. Discretiza la distribución.
  • KDE: estimación de densidad suavizada. Continua y sin sesgo de bins.
🔔
Metáfora
"La distribución normal es la firma matemática del caos ordenado. Alturas humanas, errores de medición, calificaciones de un examen justo — aparece en casi todo. Es el atractor universal de los promedios."
Caso Real
Spotify detectó distribución bimodal en duración de canciones (~3 min pop, ~7 min progresivo). Esto guió el diseño del algoritmo de recomendación por segmentos.
Python
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# Normal: alturas
sns.histplot(np.random.normal(170, 8, 1000),
  ax=axes[0], kde=True, color='#7c3aed')

# Sesgada derecha: ingresos
sns.histplot(np.random.exponential(50000, 1000),
  ax=axes[1], kde=True, color='#00d4ff')

# Bimodal
bimodal = np.concatenate([
  np.random.normal(25, 3, 500),
  np.random.normal(55, 3, 500)
])
sns.histplot(bimodal, ax=axes[2],
  kde=True, color='#10b981')

for ax, t in zip(axes,
    ['Normal', 'Sesgada derecha', 'Bimodal']):
  ax.set_title(t)
  ax.set_facecolor('#111827')
plt.tight_layout()
plt.show()

95% μ ± 2σ
99.7% μ ± 3σ
Análisis Exploratorio · Tema 4
Variables Categóricas y Análisis Bivariado
Escalas de medición · Tablas de contingencia · Relaciones entre variables

Escalas de medición

  • Nominal: categorías sin orden. Ciudad, color, género.
  • Ordinal: categorías con orden. Nivel educativo, satisfacción (1-5).
  • Intervalo: diferencias iguales, sin cero absoluto. Temperatura en °C.
  • Razón: cero absoluto significativo. Peso, altura, ingresos.

Análisis bivariado

  • Numérico–numérico: scatter plot + correlación de Pearson
  • Categórico–numérico: boxplot por grupo
  • Categórico–categórico: tabla de contingencia + heatmap
📦
Metáfora
"Las variables categóricas son como cajas de clasificación postal: no puedes sumar 'CDMX + Monterrey', pero sí contar cuántos paquetes llegan a cada ciudad y calcular el tiempo promedio de entrega por destino."
Caso Real
LinkedIn usa análisis bivariado en su Informe de Equidad cruzando género (categórica) con salario (numérica) en 50+ industrias para detectar y reportar brechas salariales.
Python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Tabla de contingencia normalizada
tabla = pd.crosstab(
  df['genero'],
  df['departamento'],
  normalize='index'
) * 100

# Heatmap de distribución
sns.heatmap(tabla, annot=True,
  fmt='.1f', cmap='Purples',
  linewidths=0.5)
plt.title('Distribución por género y dpto (%)')

# Boxplot bivariado
sns.boxplot(
  data=df,
  x='nivel_educativo',
  y='salario',
  order=['Bachillerato', 'Licenciatura',
         'Maestría', 'Doctorado'],
  palette='viridis'
)
plt.show()
Modelado Estadístico · Tema 5
Correlación de Pearson y Regresión Lineal
Coeficiente r · Mínimos cuadrados · R² · Correlación ≠ Causalidad

Correlación de Pearson (r)

  • Rango: −1 a +1
  • |r| > 0.7: correlación fuerte
  • 0.4 – 0.7: correlación moderada
  • |r| < 0.4: correlación débil
  • r = 0 → no hay relación lineal (puede existir otra relación)

Regresión lineal simple

  • Modelo: y = β₀ + β₁x + ε
  • β₀: intercepto (valor base)
  • β₁: pendiente (cambio en y por unidad de x)
  • Mínimos cuadrados: minimiza la suma de (y − ŷ)²
  • R²: proporción de varianza explicada por el modelo (0–1)
🌡️🍦
Metáfora
"r=0.95 significa que si mides la temperatura, puedes predecir las ventas de helado con 95% de acierto usando solo esa variable. r=0.02 significa que lanzar una moneda te daría el mismo resultado que tu modelo."
Caso Real
Bodega Aurrerá encontró r=0.87 entre temperatura exterior y ventas de cerveza. Usan el pronóstico del clima para predecir inventario con 3 días de anticipación.
Python
from sklearn.linear_model import LinearRegression
from scipy.stats import pearsonr

# Correlación con valor p
r, p = pearsonr(
  df['horas_estudio'],
  df['calificacion']
)
print(f"r = {r:.3f}  (p = {p:.4f})")
print(f"{'Fuerte' if abs(r)>0.7 else 'Moderada'}")

# Regresión lineal
modelo = LinearRegression()
modelo.fit(df[['horas_estudio']],
           df['calificacion'])

print(f"Por cada hora adicional de estudio:")
print(f"  sube {modelo.coef_[0]:.2f} puntos")
print(f"R² = {modelo.score(
  df[['horas_estudio']],
  df['calificacion']):.3f}")

# ⚠️ Correlación ≠ Causalidad
# r alto no implica que X causa Y

Advertencia importante

Correlación NO implica causalidad. El número de helados vendidos correlaciona con ahogamientos — ambos son causados por el calor, no uno por el otro. Siempre busca la variable oculta.

Inferencia Estadística · Tema 6
Pruebas Estadísticas y Distribuciones Muestrales
TLC · Intervalos de confianza · Prueba t · p-valor

Conceptos clave

  • Población vs muestra: inferimos la población a partir de la muestra.
  • TLC: promedios de muestras grandes (n≥30) siguen distribución normal sin importar la distribución original.
  • IC 95%: rango que contiene el parámetro real con 95% de confianza.
  • p-valor: probabilidad de observar el resultado por azar asumiendo H₀ verdadera.
  • Error tipo I (α): rechazar H₀ cuando es verdadera. Falso positivo.
  • Error tipo II (β): no rechazar H₀ cuando es falsa. Falso negativo.
🎲
Metáfora
"El Teorema del Límite Central es la magia más importante de la estadística. No importa si tu población tiene forma de dinosaurio en histograma — si tomas muestras de tamaño 30+, sus promedios siempre forman una campana. Es física del caos."
Caso Real
Mercado Libre usa pruebas t para validar que los cambios en su algoritmo de búsqueda mejoran el CTR antes de aplicar el cambio globalmente (roll-out gradual).
Python
from scipy import stats
import numpy as np

# ¿La capacitación mejoró las ventas?
antes   = [85, 92, 78, 90, 88, 76, 95, 83]
despues = [91, 98, 85, 95, 93, 82, 101, 89]

t, p = stats.ttest_rel(antes, despues)
print(f"t-estadístico: {t:.3f}")
print(f"p-valor:       {p:.4f}")

if p < 0.05:
  print("Mejora significativa ✓")
else:
  print("Sin evidencia de mejora ✗")

# IC 95% para la diferencia media
diffs = np.array(despues) - np.array(antes)
ic = stats.t.interval(
  0.95,
  df=len(diffs) - 1,
  loc=np.mean(diffs),
  scale=stats.sem(diffs)
)
print(f"IC 95%: [{ic[0]:.2f}, {ic[1]:.2f}] pts")
α=0.05 Umbral estándar
n≥30 Activa TLC
95% Confianza IC
Experimentación · Tema 7
Pruebas A/B
Experimentos controlados · Hipótesis · Tamaño de muestra · Errores comunes

Diseño del experimento

  • H₀: no hay diferencia entre grupos (hipótesis nula)
  • H₁: existe diferencia significativa (hipótesis alternativa)
  • Grupo control: versión original (A)
  • Grupo tratamiento: versión modificada (B)
  • Aleatorización: asignación aleatoria para eliminar sesgos
  • Poder estadístico: probabilidad de detectar un efecto real (β=0.8)

Errores comunes

  • P-hacking: parar la prueba cuando el p<0.05 aparece
  • Múltiples comparaciones: sin corrección de Bonferroni
  • Muestra insuficiente: resultados espurios
  • Significancia práctica: p<0.05 no implica impacto real
🔴🟢
Metáfora
"Una prueba A/B es el método científico aplicado al negocio: en lugar de opinar '¿cuál botón convierte más, el rojo o el verde?', lo pruebas con datos reales. La opinión del CEO no vale contra datos de 10,000 usuarios."
Caso Real
Booking.com ejecuta >1,000 pruebas A/B simultáneas. El cambio del color del botón "Reservar" en México aumentó conversiones 12% — validado estadísticamente antes del roll-out global.
Python
from statsmodels.stats.proportion import \
  proportions_ztest
from statsmodels.stats.power import \
  NormalIndPower

# Calcular tamaño de muestra necesario
analysis = NormalIndPower()
n = analysis.solve_power(
  effect_size=0.05,
  alpha=0.05,
  power=0.8
)
print(f"Muestra por grupo: {int(n):,}")

# Resultados del experimento
conv_A, n_A = 48, 200  # botón rojo
conv_B, n_B = 67, 200  # botón verde

z, p = proportions_ztest(
  [conv_A, conv_B],
  [n_A, n_B]
)
print(f"Tasa A: {conv_A/n_A:.1%}")
print(f"Tasa B: {conv_B/n_B:.1%}")
uplift = (conv_B/n_B - conv_A/n_A) / (conv_A/n_A)
print(f"Uplift: +{uplift:.1%}")
print(f"p = {p:.4f} → {'Significativo' if p<0.05 else 'No sig.'}")
Procesamiento de Texto · Tema 8
Introducción a NLP
Tokenización · TF-IDF · Análisis de sentimientos · Naive Bayes

Pipeline NLP

  • Tokenización: dividir texto en palabras o frases.
  • Stopwords: palabras sin contenido semántico (de, la, el). Se eliminan.
  • Stemming: reducir a raíz ("corriendo" → "corr").
  • Lematización: reducir a forma base con contexto ("fue" → "ser").
  • TF-IDF: frecuencia del término × inverso de frecuencia en corpus. Pondera relevancia.
  • Naive Bayes: clasificador probabilístico eficiente para texto.
📚
Metáfora
"Enseñar a una computadora a leer es como enseñar a un niño: primero aprende letras (tokens), luego ignora artículos (stopwords), luego reconoce que 'corriendo' y 'correr' son lo mismo (stemming) y finalmente entiende el contexto. El NLP comprime siglos de lingüística en líneas de código."
Caso Real
Rappi procesa +500,000 reseñas de restaurantes mensuales con NLP. Detecta automáticamente menciones de "frío", "tardó" o "incorrecto" para alertar restaurantes en tiempo real y proteger su NPS.
Python
from sklearn.feature_extraction.text import \
  TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline

corpus = [
  "excelente servicio rápido muy recomendado",
  "pésima experiencia nunca más vuelvo",
  "producto de calidad llegó a tiempo perfecto",
  "terrible tardó tres semanas y llegó roto",
  "increíble atención al cliente cinco estrellas"
]
y = [1, 0, 1, 0, 1]  # 1=positivo, 0=negativo

pipeline = Pipeline([
  ('tfidf', TfidfVectorizer(
    max_features=5000,
    ngram_range=(1, 2),
    strip_accents='unicode')),
  ('nb', MultinomialNB(alpha=0.1))
])
pipeline.fit(corpus, y)

nueva = ["increíble calidad llegó rápido"]
pred = pipeline.predict(nueva)
prob = pipeline.predict_proba(nueva)
print(f"{'Positiva' if pred[0]==1 else 'Negativa'}")
print(f"Confianza: {max(prob[0]):.1%}")
