Tema 1 de 8

Fundamentos de Python

El lenguaje que democratizó el análisis de datos — y por qué debes dominarlo.

¿Qué es Python?

  • Interpretado: el código se ejecuta línea por línea — sin compilar, resultados inmediatos.
  • Multiparadigma: puedes programar de forma imperativa, orientada a objetos o funcional.
  • Sintaxis limpia: la indentación fuerza código legible por humanos.
  • Creado por Guido van Rossum en 1991 — el nombre viene de Monty Python, no de la serpiente.
  • Domina en datos: ecosistema (NumPy, Pandas, Scikit-learn, TensorFlow) sin rival.

Tipos de datos primitivos

int — enteros float — decimales str — texto bool — verdadero/falso

Los operadores funcionan de forma intuitiva: + - * / // % **.

Los condicionales if / elif / else controlan el flujo del programa sin llaves — solo con indentación de 4 espacios.

💬
Metáfora: "Python es el lenguaje de los datos porque es como hablar en voz alta — claro, legible, sin ceremonias. Mientras otros lenguajes exigen que uses traje de etiqueta para ir al supermercado, Python te deja ir en ropa cómoda."
Python
# Variables: diferentes tipos
nombre = "Ana"
edad = 28
salario = 45000.50
es_analista = True

# f-string: formato moderno
print(f"{nombre} tiene {edad} años")
print(f"Salario: ${salario:,.2f}")

# Condicional
if es_analista and edad < 30:
    print("Analista junior — gran potencial")
elif edad >= 30:
    print("Analista senior")
else:
    print("Rol no definido")

Cada vez que tu pantalla de inicio carga, algoritmos escritos en Python — con exactamente las mismas variables, condicionales y tipos de datos que ves aquí — calculan en milisegundos qué 40 títulos te mostrarán de entre un catálogo de miles.

Cada línea de código que aprendes hoy es la misma que decide qué serie te muestra mañana.

Tema 2 de 8

Estructuras de Datos y Funciones

Organiza, almacena y reutiliza — los bloques esenciales de cualquier programa.

📋 Lista

Colección ordenada y mutable. Se indexa desde 0. Permite duplicados.

nums = [1, 2, 3]
nums.append(4)
nums[0] → 1

🔒 Tupla

Colección ordenada e inmutable. Más rápida que lista. Ideal para datos que no cambian.

coords = (19.43, -99.13)
lat, lon = coords

📖 Diccionario

Colección de pares clave:valor. Búsqueda O(1). Mutable. No permite claves duplicadas.

d = {"id": 1, "nom": "Ana"}
d["id"] → 1

📱
Metáfora: "Un diccionario en Python es como tu lista de contactos del teléfono: buscas por nombre (clave) y obtienes el número (valor) instantáneamente — sin recorrer toda la agenda uno por uno."
Python
# Diccionarios anidados
empleados = {
    "Ana": {"edad": 28, "dept": "Datos"},
    "Luis": {"edad": 34, "dept": "ML"}
}

# Función con parámetros y return
def saludo(nombre):
    info = empleados.get(nombre, {})
    return f"Hola {nombre}, área: {info.get('dept','N/A')}"

print(saludo("Ana")) # Hola Ana, área: Datos
print(saludo("Pedro")) # Hola Pedro, área: N/A

# Importar módulo externo
import math
print(math.sqrt(144)) # 12.0

Funciones def

  • Parámetros por defecto: def fn(x, y=10)
  • *args: número variable de argumentos posicionales.
  • **kwargs: número variable de argumentos nombrados.
  • Módulos: archivos .py reutilizables. Paquetes: carpetas con __init__.py.
Caso Real

Uber usa diccionarios anidados para mapear conductores, rutas y tarifas en tiempo real. Cuando pides un viaje, el backend en Python consulta estructuras como {driver_id: {lat, lon, rating, tarifa}} para encontrar al conductor óptimo en milisegundos entre miles de opciones activas simultáneamente.

Tema 3 de 8

Programación Funcional

Transforma datos con elegancia: map, filter, reduce y la filosofía declarativa.

Imperativo vs. Declarativo

  • Imperativo: dices cómo hacerlo paso a paso (bucle for, variable acumuladora…).
  • Declarativo: dices qué quieres obtener (map, filter, comprensión de lista).
  • map(fn, lista): aplica una función a cada elemento. Retorna iterador.
  • filter(fn, lista): conserva solo los elementos donde fn retorna True.
  • reduce(fn, lista): colapsa la lista en un único valor (del módulo functools).
  • lambda: función anónima de una sola expresión. lambda x: x * 2
  • List comprehension: la forma más "pythónica" y eficiente en velocidad.
🏭
Metáfora: "map() es como una fábrica de ensamblaje: metes materia prima (lista), defines la transformación (función lambda) y del otro lado de la cinta transportadora sale el producto terminado — sin escribir un solo loop."
Python
ventas = [120, 85, 200, 45, 310]

# Forma imperativa (loop for)
resultado_imp = []
for v in ventas:
    if v > 100:
        resultado_imp.append(v * 0.9)

# Forma funcional (filter + map)
grandes = list(filter(lambda x: x > 100, ventas))
con_desc = list(map(lambda x: x * 0.9, grandes))

# List comprehension (más pythónico ✓)
resultado = [v * 0.9 for v in ventas if v > 100]
print(resultado) # [108.0, 180.0, 279.0]

# reduce: suma total
from functools import reduce
total = reduce(lambda a,b: a+b, ventas)
print(f"Total: {total}") # 760
Caso Real

Amazon procesa millones de consultas de productos por segundo. Sus sistemas de búsqueda aplican cadenas de filter() y map() para filtrar por categoría, precio, calificación y disponibilidad simultáneamente, devolviendo resultados ordenados en menos de 100 milisegundos.

Las list comprehensions de Python son hasta 35% más rápidas que loops equivalentes por estar optimizadas a nivel de bytecode — exactamente por eso Amazon y otras tech-companies las prefieren para pipelines de alta frecuencia.

Tema 4 de 8

Pandas y Análisis Exploratorio (EDA)

Carga, inspecciona y comprende tus datos antes de analizarlos.

Series y DataFrame

  • Series: arreglo unidimensional con índice. Como una columna de Excel.
  • DataFrame: tabla bidimensional — filas × columnas. La estructura central de Pandas.
  • read_csv() — carga archivos CSV en segundos, incluso de millones de filas.
  • head(n) / tail(n) — primeras/últimas n filas.
  • info() — tipos de datos, filas no nulas, uso de memoria.
  • describe() — estadísticos descriptivos: media, std, percentiles.
  • value_counts() — frecuencias por categoría.
El flujo EDA
1
Cargar

read_csv / read_excel / read_sql

2
Inspeccionar

shape, dtypes, head

3
Limpiar

nulos, tipos, duplicados

4
Analizar

groupby, describe, viz

⚡
Metáfora: "Un DataFrame es una hoja de Excel con superpoderes: filtra 10 millones de filas en milisegundos, sin que la computadora sude. Excel se congela con 100 mil filas — Pandas sonríe con 100 millones."
Python · Pandas EDA
import pandas as pd

df = pd.read_csv("ventas.csv")

# Dimensiones del dataset
print(df.shape) # (50000, 12)

# Tipos de datos por columna
print(df.dtypes)

# Estadísticos descriptivos
print(df.describe())

# Detectar valores faltantes
print(df.isnull().sum())

# Frecuencias de una categoría
print(df['region'].value_counts())

# Filtro rápido
grandes = df[df['monto'] > 5000]
print(f"Ventas grandes: {len(grandes)}")
Caso Real

El equipo de datos de BBVA México usa Pandas para limpiar y explorar millones de transacciones diarias antes de pasar al motor de detección de fraude.

El EDA es su primera línea de defensa: con describe() detectan montos anómalos; con value_counts() identifican comercios inusuales; con isnull().sum() encuentran campos obligatorios vacíos — todo en segundos, antes de entrenar un solo modelo.

Regla de oro del análisis de datos: nunca confíes en un dataset sin haberlo inspeccionado primero.

Tema 5 de 8

Funciones Vectorizadas y Limpieza de Datos

Garbage in, garbage out — los datos sucios arruinan hasta el mejor modelo.

🗑️ Valores nulos

  • dropna() — elimina filas/columnas con NaN.
  • fillna(valor) — rellena con media, mediana o constante.
  • Regla: nunca elimines sin entender por qué faltan los datos.

🔄 Tipos incorrectos

  • astype() — convierte tipo de columna.
  • pd.to_numeric(errors='coerce') — convierte y hace NaN lo inválido.
  • pd.to_datetime() — parsea fechas de cualquier formato.

📝 Texto sucio

  • .str.strip() — elimina espacios extra.
  • .str.title() — capitaliza correctamente.
  • .str.replace() — reemplazos con regex.
  • drop_duplicates() — elimina filas repetidas.
🍳
Metáfora: "Limpiar datos es como preparar ingredientes antes de cocinar. El mejor chef del mundo no puede salvar una receta con ingredientes podridos. Un modelo de Machine Learning entrenado con datos sucios solo aprende a ser mejor en predecir basura."
Python · Data Cleaning
import pandas as pd

# 1) Convertir columna numérica con texto basura
df['edad'] = pd.to_numeric(df['edad'], errors='coerce')

# 2) Rellenar nulos con la mediana
df['edad'].fillna(df['edad'].median(), inplace=True)

# 3) Eliminar duplicados por ID único
df.drop_duplicates(subset='id_cliente', inplace=True)

# 4) Normalizar texto: quitar espacios y capitalizar
df['nombre'] = df['nombre'].str.strip().str.title()

# 5) Parsear fechas
df['fecha'] = pd.to_datetime(df['fecha'], dayfirst=True)
df['mes'] = df['fecha'].dt.month

# Reporte final de calidad
print(f"Nulos restantes: {df.isnull().sum().sum()}")
print(f"Filas únicas: {len(df)}")
Caso Real

En el IMSS, antes de analizar registros médicos de 50 millones de personas, el equipo de data science dedica el 60% del tiempo del proyecto a limpiar datos.

Los problemas encontrados: fechas de nacimiento escritas en 14 formatos diferentes, campos de diagnóstico con texto libre lleno de abreviaciones sin estándar, edades registradas como "veintiocho" (texto), campos de sexo con 7 variantes distintas de M/F.

El proceso de limpieza con Pandas redujo los errores en modelos predictivos de mortalidad hospitalaria en un 34% — no por mejores algoritmos, sino por mejores datos.

Tema 6 de 8

APIs, Automatización y Concatenación

Conecta tu código con el mundo real — extrae datos de cualquier servicio web.

Protocolo HTTP y REST APIs

  • GET: solicitar datos (leer). POST: enviar datos (crear).
  • JSON: JavaScript Object Notation — el formato universal de intercambio de datos en APIs. Se parece a un diccionario Python.
  • Status codes: 200 OK, 404 Not Found, 429 Rate Limit, 500 Server Error.
  • requests: la librería Python estándar para consumir APIs HTTP.
  • pd.concat(): une múltiples DataFrames verticalmente (como apilar tablas).
  • Automatización: for loop sobre endpoints → concatenar resultados → un solo DataFrame.
🍽️
Metáfora: "Una API es como un mesero en un restaurante: tú haces el pedido (request), él va a la cocina (servidor) y te trae exactamente lo que pediste (response JSON). No necesitas saber cómo se cocinó — solo el formato del menú."
Python · requests + Pandas
import requests, pandas as pd

# GET a una API pública de tipos de cambio
url = "https://api.exchangerate-api.com/v4/latest/MXN"
resp = requests.get(url)
datos = resp.json() # convierte JSON → dict Python

# Crear DataFrame desde el JSON
tasas = pd.DataFrame(
    list(datos['rates'].items()),
    columns=['moneda', 'tasa']
)
print(tasas[tasas['moneda'].isin(['USD','EUR','GBP'])])

# Automatizar múltiples páginas
dfs = []
for pagina in range(1, 6):
    r = requests.get(f"https://api.ejemplo.com/data?page={pagina}")
    dfs.append(pd.DataFrame(r.json()['items']))
df_total = pd.concat(dfs, ignore_index=True)
Caso Real

El SAT México expone APIs para consultar el estado fiscal de contribuyentes. Empresas como Finkargo — fintech de financiamiento para importadores — automatizan con Python la validación de proveedores: consultan la API del SAT, la del IMSS y la del Buró de Crédito en cadena, concatenan los resultados en un DataFrame y en menos de 5 segundos emiten una calificación de riesgo crediticio.

Lo que antes tomaba 3 días de trabajo manual, hoy es un script de 40 líneas en Python.

Tema 7 de 8

Transformación, Filtración y Reordenamiento

De datos planos a insights accionables con groupby, agg y pivot tables.

🎯 Selección avanzada

  • .loc[filas, cols] — por etiqueta (nombre).
  • .iloc[i, j] — por posición entera.
  • Boolean indexing: df[df['col'] > 100]
  • .query() — sintaxis SQL-like más legible.

📊 groupby + agg

  • Agrupa filas por uno o más valores de columna.
  • .agg() aplica múltiples funciones en paralelo.
  • sum, mean, count, min, max, std
  • Named aggregations: nombra los resultados limpiamente.

🔀 Pivot Tables

  • pd.pivot_table() — versión programática de la tabla dinámica de Excel.
  • sort_values() — ordena por columna ascendente o descendente.
  • reset_index() — convierte índices de groupby en columnas normales.
🎵
Metáfora: "groupby() es como organizar tu biblioteca de música por género: de miles de canciones mezcladas, de repente tienes carpetas ordenadas y puedes calcular cuántas canciones de rock tienes, cuál es la más larga, o cuál artista domina cada categoría."
Python · groupby avanzado
# Resumen de ventas por región y categoría
resumen = (
    df.groupby(['region', 'categoria'])
      .agg(
          total_ventas=('monto', 'sum'),
          num_transacciones=('id', 'count'),
          ticket_promedio=('monto', 'mean')
      )
      .sort_values('total_ventas', ascending=False)
      .reset_index()
)

# Top 5 regiones
print(resumen.head(5))

# Pivot table: región × categoría
pivot = pd.pivot_table(
    df, values='monto', index='region',
    columns='categoria', aggfunc='sum',
    fill_value=0
)
Caso Real

Walmart México opera más de 3,000 tiendas. Su equipo de analytics ejecuta pipelines de groupby() sobre millones de transacciones diarias para agrupar ventas por tienda, hora del día, categoría de producto y día de la semana.

El resultado alimenta un sistema de decisión automática: si la leche en una tienda de Monterrey lleva 4 horas con ventas 40% por encima del promedio, el sistema genera una orden de reabastecimiento en tiempo real — sin intervención humana.

Este proceso, que antes requería reportes semanales manuales en Excel, ahora corre cada 15 minutos en Python.

Tema 8 de 8

Merge y Agrupaciones — Bases de Datos con Pandas

Une tablas como SQL — combina fuentes de datos para obtener la imagen completa.

Tipos de Join

  • INNER JOIN: solo filas que tienen coincidencia en ambas tablas.
  • LEFT JOIN: todas las filas de la tabla izquierda; NaN donde no hay coincidencia en la derecha.
  • RIGHT JOIN: todas las filas de la tabla derecha.
  • OUTER JOIN: todas las filas de ambas tablas; NaN donde no hay coincidencia.
  • pd.concat(): apila tablas verticalmente (mismas columnas). pd.merge(): las une horizontalmente por clave.
  • Los parámetros left_on / right_on permiten unir columnas con nombres distintos.
💍
Metáfora: "Un merge es como una boda entre dos tablas: el INNER JOIN es cuando ambos novios llegan a la ceremonia; el LEFT JOIN es cuando el novio de la izquierda siempre está — aunque la novia no aparezca, el registro queda con los datos que faltan marcados como NaN."
Python · pd.merge()
# Tablas separadas
clientes = pd.read_csv("clientes.csv")
# Columnas: id, nombre, ciudad, segmento

pedidos = pd.read_csv("pedidos.csv")
# Columnas: id_cliente, producto, monto, fecha

# LEFT JOIN: todos los pedidos + datos del cliente
completo = pd.merge(
    pedidos, clientes,
    left_on='id_cliente', right_on='id',
    how='left'
)

# Ventas totales por ciudad
print(completo.groupby('ciudad')['monto'].sum())

# Detectar pedidos sin cliente asociado
huerfanos = completo[completo['nombre'].isnull()]
print(f"Pedidos sin cliente: {len(huerfanos)}")
Caso Real

Rappi procesa cientos de miles de pedidos diarios en LATAM. Su backend combina en tiempo real:

• Tabla pedidos (qué pidió el usuario, cuándo, monto)
• Tabla restaurantes (ubicación, tiempo de preparación promedio, comisión)
• Tabla repartidores (posición GPS actualizada, rating, pedidos activos)

El pd.merge() equivalente (en su stack de producción) une estas tres tablas para calcular el ETA, la comisión del repartidor y el precio final del pedido — todo en menos de 200 milisegundos por transacción.
