Tema 1

¿Qué es Machine Learning?

Del programa explícito al aprendizaje automático

Definición y contexto

Arthur Samuel (1959): "Campo de estudio que da a las computadoras la capacidad de aprender sin ser programadas explícitamente."

ML es un subcampo de la Inteligencia Artificial. La jerarquía es: IA ⊃ ML ⊃ Deep Learning ⊃ IA Generativa.

Diferencia clave:
Programación clásica: Datos + Reglas → Respuestas
Machine Learning: Datos + Respuestas → Reglas

Flujo de trabajo en ML

  • 1. Recopilar datos — fuentes relevantes, volumen suficiente
  • 2. Preprocesar — limpiar, normalizar, feature engineering
  • 3. Dividir — train / validation / test
  • 4. Entrenar — ajustar parámetros del modelo
  • 5. Evaluar — métricas en datos no vistos
  • 6. Optimizar — hyperparameter tuning
  • 7. Desplegar — modelo en producción

Tema 2

Separación, Validación y Evaluación

¿Cómo saber si tu modelo realmente aprendió?

División de datos

  • Train (70%) — ajusta los parámetros del modelo
  • Validation (15%) — afina hiperparámetros sin contaminar test
  • Test (15%) — evaluación final, se toca una sola vez
  • K-Fold Cross Validation — k iteraciones, cada fold es validación una vez; el resultado final es el promedio ± desviación estándar

Overfitting vs Underfitting

Overfitting (sobreajuste): alta exactitud en train, baja en test. El modelo memorizó los datos de entrenamiento.

Underfitting (subajuste): baja exactitud en ambos. El modelo es demasiado simple para capturar los patrones.

Soluciones overfitting: más datos, regularización, dropout, cross-validation, reducir complejidad del modelo.

Tema 3

Algoritmos No Supervisados

Descubrir estructura sin necesitar etiquetas

K-Means Clustering

Objetivo: agrupar n puntos en k clusters donde cada punto pertenece al cluster con el centroide más cercano.

Algoritmo iterativo:

  • 1. Inicializar k centroides aleatoriamente (o con K-Means++)
  • 2. Asignar cada punto al centroide más cercano (distancia Euclidiana)
  • 3. Recalcular centroides como promedio de cada cluster
  • 4. Repetir pasos 2-3 hasta convergencia (centroides no se mueven)

Elegir k: Método del codo (inercia vs k) o índice de silueta (cohesión interna vs separación externa).

Otros algoritmos

  • DBSCAN — clusters de forma arbitraria, detecta outliers como ruido. No requiere especificar k.
  • Hierarchical Clustering — dendrograma jerárquico, útil para exploración
  • PCA — reducción de dimensionalidad, visualiza datos de alta dimensión en 2D/3D
  • Isolation Forest — detección de anomalías, aísla outliers con árboles aleatorios
  • t-SNE / UMAP — visualización no lineal de embeddings de alta dimensión
Metáfora
🎉

K-Means es organizar una fiesta sin lista de invitados: pones mesas al azar, cada persona se sienta con quien tiene más en común, mueves la mesa al centro de cada grupo, repites hasta que nadie quiere cambiarse de mesa. Cada iteración mejora la organización hasta encontrar el equilibrio natural.

clustering.py
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

# Segmentación de clientes por RFM (Recencia, Frecuencia, Monto)
kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
clusters = kmeans.fit_predict(X_rfm_scaled)

# Evaluar calidad con índice de silueta (-1 a 1, más alto = mejor)
sil = silhouette_score(X_rfm_scaled, clusters)
print(f"Índice de silueta: {sil:.3f}")

# Método del codo para elegir k óptimo
inercias = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    inercias.append(km.fit(X_rfm_scaled).inertia_)

# Visualizar clusters con PCA (reducción a 2D)
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_rfm_scaled)
print(f"Varianza explicada: {pca.explained_variance_ratio_.sum():.1%}")

Tema 4

Regresión Lineal y Polinomial

Predecir valores continuos con modelos paramétricos

Regresión Lineal

Simple: ŷ = β₀ + β₁x (una variable predictora)

Múltiple: ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ

Mínimos Cuadrados (OLS): minimiza Σ(yᵢ − ŷᵢ)² — la suma de errores al cuadrado.

Supuestos clave: linealidad, homocedasticidad (varianza constante del error), independencia de residuos, no multicolinealidad.

Regularización y Regresión Polinomial

  • Ridge (L2): penaliza coeficientes grandes. Shrinkage sin eliminar variables.
  • Lasso (L1): puede llevar coeficientes a exactamente 0. Selección automática de variables.
  • ElasticNet: combinación de Ridge + Lasso.
  • Regresión Polinomial: agrega términos xⁿ para capturar relaciones no lineales. Cuidado: grado alto = overfitting.
Metáfora
📏

La regresión lineal traza la mejor línea recta a través de una nube de puntos — la que minimiza la suma de las distancias verticales al cuadrado de cada punto a la línea. Es como tensar un hilo entre clavos dispersos buscando el equilibrio perfecto donde la tensión total sea mínima.

regresion.py
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline
from sklearn.metrics import r2_score, mean_squared_error
import numpy as np

# Regresión múltiple
lr = LinearRegression()
lr.fit(X_train, y_train)
y_pred = lr.predict(X_test)
print(f"R²:   {r2_score(y_test, y_pred):.3f}")
print(f"RMSE: ${np.sqrt(mean_squared_error(y_test, y_pred)):,.0f}")

# Pipeline polinomial grado 3 + Ridge regularización
poly_ridge = Pipeline([
    ('poly',  PolynomialFeatures(degree=3, include_bias=False)),
    ('ridge', Ridge(alpha=1.0))
])
poly_ridge.fit(X_train, y_train)
print(f"R² polinomial: {poly_ridge.score(X_test, y_test):.3f}")

# Lasso para selección de variables
lasso = Lasso(alpha=0.01)
lasso.fit(X_train, y_train)
activas = sum(lasso.coef_ != 0)
print(f"Variables activas Lasso: {activas} de {X_train.shape[1]}")

Tema 5

Árboles de Decisión y Random Forest

De la interpretabilidad a la robustez por diversidad

Árbol de Decisión

Estructura jerárquica de preguntas binarias (nodos) que dividen el espacio de features hasta llegar a predicciones (hojas).

Criterio de división: Gini Impurity (clasif.) o Varianza (regresión). En cada nodo, elige el split que maximiza la ganancia de información.

Hiperparámetros clave: max_depth (profundidad máxima), min_samples_split (muestras mínimas para dividir), min_samples_leaf.

Ventajas: interpretable, no requiere escalado, maneja categóricas.

Random Forest

Ensemble de N árboles, cada uno entrenado en un subconjunto aleatorio de datos (Bootstrap Aggregation = Bagging) y features (Feature Randomness).

Predicción: clasificación = moda de N árboles; regresión = promedio.

Por qué funciona: árboles diversos cometen errores diferentes. La diversidad cancela los errores individuales — la sabiduría de la multitud.

Feature Importance: mide cuánto contribuye cada variable a reducir impureza en promedio.

Metáfora
🌳

Un árbol de decisión es el juego "20 preguntas": ¿tiene más de 100 empleados? ¿está en el norte? ¿factura más de $1M? Cada respuesta te acerca a la predicción. Random Forest es jugar 500 partidas con diferentes expertos y tomar la respuesta más votada — los errores individuales se cancelan mutuamente.

random_forest.py
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.ensemble import RandomForestClassifier
import pandas as pd

# Árbol simple — interpretable para explicar al negocio
dt = DecisionTreeClassifier(max_depth=4, random_state=42)
dt.fit(X_train, y_train)
print(export_text(dt, feature_names=feature_names))

# Random Forest — robusto para producción
rf = RandomForestClassifier(
    n_estimators=200,   # número de árboles
    max_depth=10,        # controla overfitting
    min_samples_split=5, # mínimo para dividir nodo
    max_features='sqrt', # features aleatorias por split
    random_state=42)
rf.fit(X_train, y_train)

importancias = (pd.Series(rf.feature_importances_, index=feature_names)
                  .sort_values(ascending=False))
print("Top 5 variables más importantes:")
print(importancias.head(5).round(3))
print(f"Accuracy: {rf.score(X_test, y_test):.3f}")

Tema 6

Redes Neuronales Artificiales

Inspiradas en el cerebro, entrenadas con datos

Fundamentos

Neurona artificial (Perceptrón): z = Σ(wᵢ·xᵢ) + b → activación(z) → output

Funciones de activación:

  • ReLU max(0,x) — capas ocultas, evita vanishing gradient
  • Sigmoid 1/(1+e⁻ˣ) — salida binaria (0-1)
  • Softmax — salida multiclase (probabilidades que suman 1)
  • Tanh — centrada en 0, buena para capas ocultas pequeñas

Entrenamiento y regularización

Backpropagation: calcula gradiente del error capa por capa hacia atrás usando la regla de la cadena.

Gradient Descent: ajusta pesos en la dirección de menor error. Learning rate controla el tamaño del paso.

Optimizadores: SGD, Adam (adaptativo, el más usado), RMSprop.

Regularización: Dropout (apaga neuronas aleatorias), Early Stopping, Batch Normalization, L2 en pesos.

Metáfora
🚗

Aprender a conducir: al principio cometes errores (error alto). El instructor te corrige (backpropagation), ajustas tu técnica (pesos actualizados), repites. El learning rate es cuán brusco ajustas al volante — muy alto: fuera de control; muy bajo: tardas años. Dropout es practicar con los ojos tapados a veces — te fuerza a no depender de una sola señal.

red_neuronal.py
import tensorflow as tf
from tensorflow import keras

# Red neuronal para clasificación binaria (ej: fraude/no fraude)
model = keras.Sequential([
    keras.layers.Dense(128, activation='relu',
                       input_shape=(X_train.shape[1],)),
    keras.layers.Dropout(0.3),     # apaga 30% de neuronas
    keras.layers.Dense(64, activation='relu'),
    keras.layers.BatchNormalization(),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(32, activation='relu'),
    keras.layers.Dense(1, activation='sigmoid') # salida binaria
])

model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy', keras.metrics.AUC()])

history = model.fit(
    X_train, y_train,
    epochs=50, batch_size=256,
    validation_split=0.2,
    callbacks=[keras.callbacks.EarlyStopping(
        monitor='val_auc', patience=5,
        restore_best_weights=True)])

loss, acc, auc = model.evaluate(X_test, y_test, verbose=0)
print(f"Test Accuracy: {acc:.3f} | AUC: {auc:.3f}")

Tema 7

Ensemble de Clasificadores

La sabiduría colectiva supera al experto individual

Bagging

Modelos en paralelo, cada uno en subconjunto aleatorio de datos (Bootstrap). Reduce varianza. Ejemplo: Random Forest.

Boosting

Modelos en serie, cada uno corrige errores del anterior. Reduce sesgo. Ejemplos: AdaBoost, GBM, XGBoost, LightGBM.

Stacking

Usa predicciones de modelos base como features de un meta-modelo final. Combina diversidad y potencia.

Voting

Combina modelos heterogéneos. Hard: moda de predicciones. Soft: promedio de probabilidades (mejor).

Metáfora
🏥

Boosting es un equipo médico en urgencias: el primer doctor diagnostica, el segundo revisa sus errores y agrega información, el tercero refina aún más. Cada médico aprende de los errores del anterior. XGBoost hace este proceso 200 veces, aprendiendo velozmente de cada error previo.

ensemble.py
from xgboost import XGBClassifier
from sklearn.ensemble import VotingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score

# XGBoost — el favorito de las competencias de datos
xgb = XGBClassifier(
    n_estimators=200,  learning_rate=0.05,
    max_depth=6,        subsample=0.8,
    colsample_bytree=0.8, eval_metric='auc',
    random_state=42)
xgb.fit(X_train, y_train,
        eval_set=[(X_test, y_test)], verbose=False)
print(f"XGBoost AUC: {roc_auc_score(y_test, xgb.predict_proba(X_test)[:,1]):.4f}")

# Voting ensemble heterogéneo (soft = promedia probabilidades)
ensemble = VotingClassifier(
    estimators=[
        ('xgb', XGBClassifier(n_estimators=100)),
        ('rf',  RandomForestClassifier(n_estimators=100)),
        ('lr',  LogisticRegression(max_iter=500, C=0.1))
    ], voting='soft')
ensemble.fit(X_train, y_train)
auc_ens = roc_auc_score(y_test, ensemble.predict_proba(X_test)[:,1])
print(f"Ensemble AUC: {auc_ens:.4f}")

Tema 8

Procesamiento Digital de Imágenes

Enseñar a las máquinas a ver

Fundamentos de imágenes

Imagen digital: matriz de píxeles. RGB = 3 matrices (canales R, G, B) de valores 0-255. Una imagen 224×224 px en color = 3 × 224 × 224 = 150,528 valores.

OpenCV: librería estándar de visión computacional. Operaciones básicas: resize, rotate, blur (suavizado), Canny (bordes), threshold, morphology.

HOG (Histogram of Oriented Gradients): descriptor clásico para ML sobre imágenes — captura la distribución de gradientes locales de intensidad.

CNNs y Transfer Learning

CNN (Convolutional Neural Network): capas convolucionales detectan patrones locales (filtros) + capas de pooling reducen dimensión + capas densas clasifican.

Transfer Learning: reusar pesos preentrenados en ImageNet (VGG16, ResNet50, MobileNetV2). Solo re-entrenar las últimas capas. Requiere muy pocos datos.

Fine-tuning: descongelar capas profundas para adaptar al dominio específico (radiografías, productos, documentos).

Metáfora
👁️

Una CNN ve imágenes como capas de abstracción: capa 1 detecta bordes, capa 2 formas geométricas, capa 3 partes de objetos (orejas, ruedas), capa final el objeto completo. Transfer Learning es contratar a alguien que ya sabe ver objetos (entrenado en ImageNet) y solo enseñarle los tuyos específicos — en horas en lugar de semanas.
