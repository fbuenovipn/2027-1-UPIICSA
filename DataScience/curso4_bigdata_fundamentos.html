Las 5V del Big Data

Las dimensiones que definen qué es — y qué no es — Big Data

Fundamentos de Data Science y CRISP-DM

Ecosistema: IA > Machine Learning > Deep Learning. Data Science = intersección de estadística + programación + dominio del negocio. El "unicornio": mitad estadístico, mitad programador, mitad experto de dominio.

📦 Ejemplo: ¿Por qué bajan las ventas en OXXO los martes?

Modelado: regresión para factores causales

Evaluación: ¿explica el fenómeno observado?
Despliegue: dashboard automático para gerentes
🗺️
CRISP-DM es el GPS del Data Scientist. Sin él, puedes ir muy rápido en la dirección equivocada. Con él, sabes en qué fase estás, cuánto falta y cuándo debes recalcular la ruta.
CASO REAL
Liverpool aplicó CRISP-DM a abandono de carrito en e-commerce. En la fase de comprensión descubrieron que el problema eran los costos de envío (no el precio). El modelo final redujo abandono 18% y aumentó conversión 11%.
Slide 03 · Herramientas

Python para Big Data

Python: interpretado, multiparadigma (OOP + funcional), tipado dinámico. Ecosistema más rico para Big Data, integración nativa con Spark (PySpark), mayor comunidad. Vectorización NumPy vs loops Python: hasta 100× más rápido en datos grandes. Google Colab ofrece GPU/TPU gratuitos para procesamiento en la nube.
OOP aplicada a datos — Dataset encadenado
Python 
class Dataset:
    def __init__(self, nombre, fuente):
        self.nombre = nombre
        self.fuente = fuente
        self._df = None

    def cargar(self):
        import pandas as pd
        self._df = pd.read_csv(self.fuente)
        print(f"✓ {self.nombre}: {len(self._df):,} registros")
        return self  # permite encadenamiento

    def calidad(self):
        nulos = self._df.isnull().sum()
        pct = (nulos / len(self._df) * 100).round(1)
        reporte = pct[pct > 0].to_dict()
        print(f"⚠ Nulos: {reporte or 'Ninguno ✓'}")
        return self

    def resumen(self):
        print(self._df.describe().round(2))
        return self

# Encadenamiento fluido
ventas = Dataset("Ventas 2024", "ventas_2024.csv")
ventas.cargar().calidad().resumen()
Vectorización vs Loops
Python 
import numpy as np, time

datos = np.random.rand(10_000_000)

# Loop Python (lento)
t0 = time.time()
resultado = [x**2 for x in datos]
print(f"Loop: {time.time()-t0:.2f}s")

# Vectorización NumPy (rápido)
t0 = time.time()
resultado = datos**2
print(f"NumPy: {time.time()-t0:.4f}s")
# ← 100x más rápido
🏭
NumPy vs loops = fábrica vs artesano. El artesano hace 10 piezas/día con calidad perfecta. La fábrica hace 10,000. Con un millón de filas, necesitas la fábrica.
CASO REAL
El IMSS analiza 50 millones de registros de consultas médicas anuales con Python + Pandas + Dask. Detecta patrones de enfermedades emergentes 3 semanas antes de que sean visibles en medios de comunicación.

Slide 06 · Calidad de Datos

Tratamiento de Datos y EDA

GIGO: Garbage In, Garbage Out — la ley más importante de ciencia de datos. El 80% del tiempo real de un Data Scientist es limpieza y preparación. Un modelo perfecto con datos sucios produce resultados inútiles.
❓
Valores faltantes

MCAR → eliminar. MAR → imputar media/mediana. MNAR → modelo de imputación.

📍
Outliers

IQR (Q1±1.5·IQR), Z-score (|z|>3), DBSCAN. ¿Eliminar, transformar o mantener?

🔀
Inconsistencias

"01/01/2024" vs "2024-01-01". Fuzzy matching: "Juan García" ≈ "Juan Garcia".

👥
Duplicados

Exactos (fácil) vs aproximados (fuzzy matching, distancia de Levenshtein).

⚖️
Desbalance

Fraude 0.1% vs legítimo 99.9%. Técnicas: SMOTE, undersampling, class_weight.

EDA Automatizado
Python 
def eda_reporte(df, nombre="Dataset"):
    sep = "="*55
    print(f"\n{sep}\n REPORTE EDA — {nombre}")
    print(f" {df.shape[0]:,} filas × {df.shape[1]} cols")

    # 1. Valores faltantes
    nulos = df.isnull().sum()
    if nulos.any():
        print("\n⚠  VALORES FALTANTES:")
        for col, n in nulos[nulos > 0].\
                sort_values(ascending=False).items():
            pct = n/len(df)
            bar = "█" * int(pct*20)
            print(f"  {col:<25} {pct:>5.1%} {bar}")

    # 2. Duplicados
    d = df.duplicated().sum()
    print(f"\n🔄 Duplicados: {d:,} ({d/len(df):.1%})")

    # 3. Outliers IQR
    num = df.select_dtypes(include='number')
    Q1,Q3 = num.quantile(0.25), num.quantile(0.75)
    IQR = Q3 - Q1
    out = ((num < Q1-1.5*IQR)|(num > Q3+1.5*IQR)).sum()
    print("\n🔍 Outliers:", out[out > 0].to_dict())
    return df

eda_reporte(df, "Ventas Nacionales 2024")
